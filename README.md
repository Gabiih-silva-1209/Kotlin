# 🟣 Kotlin – Introdução à Linguagem

## 📌 Descrição

Projeto desenvolvido como **aula inicial de Kotlin**, com foco na compreensão da estrutura básica da linguagem e seus principais conceitos.

O objetivo foi conhecer a sintaxe, estrutura e funcionamento do Kotlin, entendendo suas diferenças em relação ao Java e sua aplicação no desenvolvimento moderno, especialmente para Android e backend.

---

## 🎯 Objetivo

* Compreender a sintaxe básica do Kotlin
* Entender a estrutura de um programa Kotlin
* Trabalhar com variáveis, funções e classes
* Explorar conceitos fundamentais da linguagem
* Criar base para evolução em projetos Android e backend

---

## 🛠️ Tecnologias Utilizadas

* Kotlin

## 📚 Conceitos Abordados

### 🔤 Estrutura Básica

* Função `main()`
* Declaração de variáveis (`val` e `var`)
* Tipos de dados (Int, String, Double, Boolean)

### 🔁 Controle de Fluxo

* Condicionais (`if`, `when`)
* Estruturas de repetição (`for`, `while`)

### 🧱 Funções

* Declaração de funções
* Parâmetros
* Retorno de valores

### 🏗️ Orientação a Objetos

* Classes
* Construtores
* Propriedades
* Métodos

### ✨ Características da Linguagem

* Sintaxe mais concisa
* Inferência de tipo
* Null Safety
* Interoperabilidade com Java
